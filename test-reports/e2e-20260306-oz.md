## Architecture Change

Rewrote MinimalAccount from 209-line custom implementation to ~33 lines using OpenZeppelin Contracts v5.6.1:

| Component | Old (custom) | New (OZ) |
|-----------|-------------|----------|
| Execution | Custom `executeBatch(Call[])` | ERC-7821 `execute(bytes32, bytes)` |
| Signature | Manual ecrecover + EIP-191 | `SignerEIP7702` (raw ECDSA) |
| 4337 | Manual `validateUserOp` | `Account` base class |
| Token Rx | ❌ | `ERC721Holder` + `ERC1155Holder` |
| ERC-165 | Manual | Automatic via inheritance |

## Key Technical Notes

1. **OZ SignerEIP7702** uses raw ECDSA: `ecrecover(hash, sig) == address(this)`. No EIP-191 prefix for UserOp signatures.
2. **MockVerifyingPaymaster** uses EIP-191 for its PM authorization signature (separate signing domain from account).
3. **ERC-7821 mode** `0x01000000...` = batch call type with ERC-7579 execution encoding.
4. **Execution encoding**: `abi.encode(Execution[])` where `Execution = (address target, uint256 value, bytes callData)`.
5. **vm.setNonce workaround** still needed — forge simulation doesn't model EIP-7702 auth nonce increment.
6. **`--gas-estimate-multiplier 500`** needed for type 4 txs but causes over-estimation for type 2 txs from delegated accounts.
