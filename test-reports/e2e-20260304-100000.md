## Key Insights

1. **Pure Forge Script E2E**: No shell wrappers needed. Single `forge script` invocation handles all 3 txs.
2. **Gas estimation**: Forge underestimates gas for type 4 (EIP-7702) txs. Use `--gas-estimate-multiplier 500` (5x).
3. **Delegation + handleOps in 1 tx**: EIP-7702 processes authorization before EVM execution, so delegation is active when `validateUserOp` runs.
4. **Deterministic Alice**: Use `block.number + block.timestamp` for fresh-per-run Alice to avoid `vm.unixTime()` non-determinism between forge simulation phases.
5. **Local hash computation**: Compute `getUserOpHash` locally in Solidity to avoid any simulation/on-chain divergence from EntryPoint state calls.
6. **UserOp gas tuning**: `verificationGasLimit=200k, callGasLimit=300k, preVerificationGas=100k, maxFeePerGas=3gwei` works reliably on Sepolia.
