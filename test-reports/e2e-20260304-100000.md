## Key Insights

1. **EIP-191 signature format**: UserOp hash wrapped with `\x19Ethereum Signed Message:\n32` before ecrecover. Signing side must use `personal_sign`.

2. **Prefund gating**: Only pays EntryPoint prefund when signature is valid (`validationData == 0`).

3. **Delegation must be carried by third party**: Auth nonce and tx nonce conflict when Alice sends her own type 4 tx.

4. **vm.setNonce workaround**: EIP-7702 auth increments Alice's nonce on-chain but forge simulation doesn't model this. `vm.setNonce(alice, 1)` after delegation step keeps nonces in sync.

5. **Gas estimation**: `--gas-estimate-multiplier 500` needed for type 4 txs.
