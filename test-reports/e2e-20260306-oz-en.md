## Key Technical Notes

1. **OZ SignerEIP7702** uses raw ECDSA: `ecrecover(hash, sig) == address(this)`. UserOp signatures have no EIP-191 prefix.
2. **VerifyingPaymaster** uses **EIP-712 typed data** with domain separator (binds to chainId + paymaster address) for replay-proof authorization. Includes Ownable2Step, Pausable, ReentrancyGuard, and signer/owner separation.
3. **ERC-7821 mode** `0x01000000...` = batch call type, using ERC-7579 execution encoding.
4. **Execution encoding**: `abi.encode(Execution[])` where `Execution = (address target, uint256 value, bytes callData)`.
5. **vm.setNonce workaround** still needed — forge simulation does not model EIP-7702 auth nonce increment.
6. **`--gas-estimate-multiplier 500`** required for type 4 transactions but causes over-estimation for type 2 txs from delegated accounts.
7. **Paymaster cleanup is two-phase**: Step 7 in E2EPaymaster calls `unlockStake()` + `withdrawTo()`. A separate `PaymasterCleanup.s.sol` script handles `withdrawStake()` after `unstakeDelay` has elapsed. This is due to a forge limitation: simulation runs all txs in a single EVM pass, so `unlockStake()` + `withdrawStake()` in the same script fails with "Stake withdrawal is not due".
