| Gas 支付方式 | EP 预存 (`depositTo`) | PM 存款 (`depositTo` + `addStake`) | API 赞助 |

| 初始化成本 | 1 笔存款交易 | 3 笔交易 (部署 PM + deposit + stake) | 0 (只需 API key) |

| 是否单独委托交易 | ❌ (在 handleOps tx 中) | ❌ (在 handleOps tx 中) | ❌ (在 bundler tx 中) |

|---|---|---|---|

| | #1 Self-Bundled | #2 Self-Paymaster | #3 Pimlico |
|---|---|---|---|

## 6. 关键技术说明

1. **Raw ECDSA：** OZ `SignerEIP7702` 使用 `ecrecover(hash, sig)`，而非 `personal_sign`。使用 `personal_sign` 的标准 ERC-4337 SDK 无法兼容。
2. **EIP-7702 委托：** 由 Alice 链下签名，由 bundler 在 type 4 tx 的 `authorizationList` 中携带。
3. **Forge gas 估算：** type 4 交易需要 `--gas-estimate-multiplier 500`。
4. **UserOp hash (v0.7)：** `keccak256(abi.encode(packHash, EP, chainId))` — 可本地计算。
5. **Paymaster EIP-712：** domain 绑定 `chainId` + paymaster 地址，防止跨链重放。
6. **两阶段 paymaster 清理：** `unlockStake` 在主脚本中执行，`withdrawStake` 在单独脚本中执行（Forge 在单个 EVM pass 中模拟）。
7. **`eip7702Auth`：** Pimlico API 参数，将委托与 UserOp 原子化捆绑。
8. **所有 USDC 金额**统一为 1 USDC (0.6 + 0.4 批量)，Sponsor → Alice → Sponsor 往返。
