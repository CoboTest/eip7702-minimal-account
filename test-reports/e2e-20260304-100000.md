## Key Insights

1. **Four actors, clean separation**: Deployer deploys, Sponsor pays for sponsorship, Bundler submits tx, Alice signs off-chain only.
2. **Pure Forge Script**: Single `forge script` invocation, no shell wrappers.
3. **Gas estimation**: Forge underestimates gas for type 4 (EIP-7702) txs → use `--gas-estimate-multiplier 500`.
4. **Delegation + handleOps in 1 tx**: EIP-7702 processes authorization before EVM execution, so delegation is active when `validateUserOp` runs.
5. **Deterministic Alice**: `block.number + block.timestamp` seed avoids `vm.unixTime()` non-determinism.
6. **Local hash computation**: `getUserOpHash` computed in Solidity to avoid simulation/on-chain divergence.
