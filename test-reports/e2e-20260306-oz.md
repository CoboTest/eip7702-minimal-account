## Architecture Change

Rewrote MinimalAccount from 209-line custom implementation to ~33 lines using OpenZeppelin Contracts v5.6.1:

| Component | Old (custom) | New (OZ) |
|-----------|-------------|----------|
| Execution | Custom `executeBatch(Call[])` | ERC-7821 `execute(bytes32, bytes)` |
| Signature | Manual ecrecover + EIP-191 | `SignerEIP7702` (raw ECDSA) |
| 4337 | Manual `validateUserOp` | `Account` base class |
| Token Rx | ❌ | `ERC721Holder` + `ERC1155Holder` |
| ERC-165 | Manual | Automatic via inheritance |

### Flow Details

1. Deployer deploys MinimalAccount + MockVerifyingPaymaster
2. Deployer funds Paymaster (0.05 ETH deposit + 0.01 ETH stake to EP)
3. Alice signs UserOp with `paymasterAndData` (Deployer signs PM authorization)
4. Bundler submits handleOps with Alice's EIP-7702 delegation
5. Alice executes a zero-value call to Deployer — **0 ETH spent by Alice**

### Paymaster Design

- **Type:** Verifying Paymaster (off-chain signature authorization)
- **PM Owner signs:** `keccak256(abi.encode(sender, nonce, validUntil, validAfter))`
- **Signature scheme:** EIP-191 personal_sign (for PM auth, separate from account signature)
- **paymasterAndData layout:** `[address][uint128 verificationGas][uint128 postOpGas][uint48 validUntil][uint48 validAfter][65-byte sig]`

## Key Technical Notes

1. **OZ SignerEIP7702** uses raw ECDSA signature (NOT EIP-191 personal_sign)
2. **ERC-7821 mode** `0x01000000...` = batch call with ERC-7579 encoding
3. **Execution encoding**: `abi.encode(Execution[])` where `Execution = (address target, uint256 value, bytes callData)`
4. **MockVerifyingPaymaster** uses EIP-191 for its own PM signature (separate from account sig)
5. **vm.setNonce workaround** still needed for EIP-7702 auth nonce increment
